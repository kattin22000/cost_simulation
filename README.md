# 残業手当計算ツール

スマートフォンでの利用を想定した、残業時間から残業手当の概算を計算するシンプルなWebアプリです。iPhone SE（第2世代）の画面サイズでも操作しやすいよう、入力欄と時間選択ピッカーをコンパクトに配置しています。

## 主な機能

- 月額賃金項目と年間所定労働時間を設定して、基礎賃金と時給を算出
- 残業時間を15分単位（0.25時間）で選択
- 次の区分ごとに金額を計算し、合計額と明細を表示
  - 割増0%（倍率1.00）
  - 割増25%（倍率0.25）
  - 割増25%（倍率1.25）
- 基本給と年間所定労働時間の必須入力チェック
- 賃金項目の未入力・負数・数値以外の値を検証（任意項目の未入力は0として扱う）
- 入力した設定値と残業時間をブラウザーの `localStorage` に保存
- 対応ブラウザーではホーム画面への追加と、Service Workerによるキャッシュを利用可能

## 計算方法

実装している計算式は次のとおりです。

- 調整手当 ＝（基本給 ＋ 職能給・勤続給 ＋ 扶養手当）× 10%
- 基礎賃金 ＝ 基本給 ＋ 調整手当 ＋ 職能給・勤続給 ＋ 役職手当
- 時給 ＝ 基礎賃金 × 12 ÷ 年間所定労働時間
- 割増0%の金額 ＝ 時給 × 対象時間
- 割増25%（倍率0.25）の金額 ＝ 時給 × 対象時間 × 0.25
- 割増25%（倍率1.25）の金額 ＝ 時給 × 対象時間 × 1.25
- 総残業手当 ＝ 上記3区分の金額の合計

計算結果の金額は1円単位に四捨五入して表示します。総残業手当は、各区分の金額を丸める前の値で合算し、表示時に四捨五入します。時給は小数第2位まで表示します。

ここに記載した計算式はアプリの実装内容を説明したものであり、個別の就業規則、法令適用、支給条件を判定するものではありません。実際の支給額は所属組織の規程等を確認してください。

## 使い方

1. アプリをブラウザーで開きます。
2. 初回起動時、または「初期設定」から、基本給・勤続職能・扶養手当・役職手当・年間所定労働時間を入力します。
3. 各残業時間欄をタップし、時間ピッカーで対象時間を選択して「確定」を押します。
4. 「計算する」を押すと、総残業手当と内訳が表示されます。明細には項目、時間、手当額が表示され、合計行には総時間と総額が表示されます。
5. 基本給と年間所定労働時間は必須です。年間所定労働時間には0より大きい値を入力してください。職能給・勤続給、扶養手当、役職手当は任意で、未入力の場合は0として計算します。賃金項目に負数や数値以外の値を入力すると、エラーメッセージが表示されます。
6. 入力値は同じブラウザー内に保存され、次回起動時に復元されます。

## iPhone SE（第2世代）向けのレイアウト

- 画面幅に合わせた2列グリッド
- セーフエリアと動的ビューポートを考慮した余白設定
- 画面高が短い場合のコンパクト表示
- 小さい画面でも内容が切れないよう、必要に応じてページやダイアログをスクロール可能にする設計
- タッチ操作を考慮した入力欄とボタンのサイズ

## ファイル構成

- `index.html`：画面、計算処理、時間ピッカー
- `manifest.json`：Webアプリとしての表示設定
- `service-worker.js`：アプリファイルのキャッシュ

## 起動方法

静的ファイルとしてWebサーバーに配置し、ブラウザーから `index.html` を開いて利用します。Service Workerやホーム画面追加などのPWA機能は、ブラウザーの対応状況と配信環境に依存します。

## データとプライバシー

入力値はブラウザーの `localStorage` に保存されます。サーバーへのデータ送信機能は実装していません。共有端末では保存された入力値に注意し、必要に応じてブラウザーのサイトデータを削除してください。

## 最終確認

- スマートフォン実機で表示と操作を確認済み
- 画面幅が狭い場合の合計額、明細表、計算条件の注記を考慮したレスポンシブ表示
- 計算結果の合計額と明細の合計行を強調表示
